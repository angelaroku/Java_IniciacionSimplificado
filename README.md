# Contexto sobre el repo: <em>"IniciacionJava_RutaSimplificada"</em>
Aquí encontraras una ruta simplificada de lo que he podido aprender de Java en este tiempo. Dentro del repo la información que dejo disponible esta ordenada de esta manera:

## <li>PDFs: Esta parte sería la "guía a seguir".</li>
El PDF que aconsejo leer primero es el de "Iniciación a la programación y el mundo informático". 
Aunque si ya sabías o tenías contexto de programación, puedes ir directamente al PDF de "Ruta Simplificada Java (Teórico-Practico)". AquÍ encontrarás mucha teoría, pero simplificada con mis palabras, también ejercicios prácticos en todos los niveles, para que según vayas entendiendo la teoría de Java puedas aplicarla e interiorizarla rápidamente.
Por último, también encontrarás un PDF llamado "Soluciones explicadas", en la que podrás ver las soluciones de los ejercicios planteados en "Ruta Simplificada Java (Teórico-Practico)".

## <li>SRCs: En esta parte podrás encontrar "proyectos modelo".</li>
Estos "proyecto modelo" se referenciarán en en algunos puntos del PDF de "Ruta Simplificada Java (Teórico-Practico)". Las recomendaciones de uso de estos archivos estarán detalladas también en el PDF mecionado anteriormente.

## <li>Otros Ficheros: Esta parte a queda disponible para posibles ficheros útiles para el aprendizaje. </li>
Las recomendaciones de uso de estos ficheros se mencionarán en alguno de los distintos PDFs.
